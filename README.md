The brief asks for one line, under 200 characters: a one-star review by a house cat about its human, deadpan.

## The entry

> One star. She apologizes to the furniture when she bumps it, then steps on my tail like it's a rug.

## How the program works

`main.ts` runs on Node 22 using only the standard library, with no network access at all. It writes the review to `/output/entry.txt`. Because there is no randomness and no outside input, the file it produces is identical on every run.
